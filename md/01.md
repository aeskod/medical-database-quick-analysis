# Development Step 1: Dataset Upload + Column Profiling MVP

## Goal

Implement the first working version of the dashboard upload page.

The goal of this step is to let a user upload a tabular dataset and immediately see a reliable, testable summary of its structure.

This step should answer:

```text
Can the app read the uploaded file?
How many rows and columns does it contain?
What are the column names?
What data type does each column appear to be?
How much data is missing in each column?
What example values does each column contain?
```

Do **not** implement survival analysis, Kaplan–Meier curves, cohort filtering, column-role mapping, Cox models, or report export in this step.

---

## Scope of Step 1

Build only the following:

```text
1. Basic Streamlit app shell
2. Upload page
3. CSV/XLSX/TSV file loading
4. Dataset preview
5. Column profiling table
6. Basic error handling for invalid uploads
7. Unit tests for profiling logic
```

---

## Non-Goals for Step 1

Do not implement:

```text
survival analysis
event/censor value mapping
required survival column mapping
data cleaning beyond basic missing-value normalization
charts
cohort overview
advanced validation
PHI detection
large-data optimization
database storage
authentication
multi-page navigation beyond placeholder tabs
```

The purpose is to create a stable foundation before adding analysis features.

# 6. Column Type Inference

Implement column type inference in:

```text
src/profiling.py
```

## Function: `infer_column_type`

Signature:

```python
def infer_column_type(series: pd.Series) -> str:
    ...
```

Return one of these type labels:

```text
empty
integer
float
numeric
boolean
date
categorical
text
id_like
mixed
```

## Type Inference Rules

Use simple deterministic rules for Step 1.

### `empty`

Return `empty` if all values are missing after missing-value normalization.

### `boolean`

Return `boolean` if non-missing values are only one of:

```text
true / false
yes / no
y / n
0 / 1
```

Case-insensitive for text values.

### `integer`

Return `integer` if all non-missing values are integers.

Examples:

```text
1, 2, 3
42, 51, 76
```

### `float`

Return `float` if all non-missing values are numeric and at least one value is non-integer.

Examples:

```text
1.2, 3.5, 8.0
```

### `date`

Return `date` if most non-missing values can be parsed as dates.

A reasonable threshold:

```text
at least 80% of non-missing values parse successfully as dates
```

### `id_like`

Return `id_like` if the column appears to be an identifier.

Suggested heuristic:

```text
unique_count / non_missing_count >= 0.95
AND
non_missing_count > 10
AND
column is not clearly numeric measurement
```

This should catch columns like:

```text
patient_id
subject_id
record_id
case_id
```

Also use column-name hints:

```text
id
patient_id
subject_id
record_id
case_id
mrn
```

If the column name contains one of these terms and values are mostly unique, classify as `id_like`.

### `categorical`

Return `categorical` if the column has relatively few unique values.

Suggested heuristic:

```text
unique_count <= 20
OR
unique_count / non_missing_count <= 0.2
```

Examples:

```text
Male / Female
Dead / Alive
A / B
Stage I / Stage II / Stage III
```

### `text`

Return `text` if values are strings and have many unique values or long average length.

Suggested heuristic:

```text
average string length > 30
OR
unique_count / non_missing_count > 0.5
```

### `mixed`

Return `mixed` if the column contains incompatible types that cannot be reliably classified.

Example:

```text
10, 12, "unknown", "high", "low"
```

# 7. Column Profiling

Implement a profiling function in:

```text
src/profiling.py
```

## Function: `profile_dataframe`

Signature:

```python
def profile_dataframe(df: pd.DataFrame) -> pd.DataFrame:
    ...
```

It should return a DataFrame with one row per column.

Required output columns:

```text
column_name
detected_type
missing_count
missing_percent
non_missing_count
unique_count
example_values
```

## Output Details

### `column_name`

Original column name from the uploaded dataset.

### `detected_type`

Output from `infer_column_type`.

### `missing_count`

Number of missing values.

### `missing_percent`

Percentage of missing values, rounded to 2 decimal places.

Example:

```text
5.33
```

### `non_missing_count`

Number of non-missing values.

### `unique_count`

Number of unique non-missing values.

### `example_values`

A short string containing up to 5 example non-missing values.

Example:

```text
Dead, Alive
```

or:

```text
55, 63, 72, 80
```
