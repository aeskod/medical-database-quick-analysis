# 05.md — Development Step 5: Cohort Overview Tab

## Goal

Implement the **Cohort Overview** tab.

The dashboard already supports:

```text
Step 1: Upload + preview + column profiling
Step 2: Survival role candidate detection + confirmed survival mapping
Step 3: Basic Kaplan–Meier survival analysis
Step 4: Data Quality tab
```

Step 5 should let the user quickly understand the uploaded patient-level cohort.

The Cohort Overview tab should answer:

```text
How many patients/rows are in the dataset?
How many rows are usable for survival analysis?
How many events and censored observations are present?
What are the main demographic/clinical characteristics?
How are variables distributed overall?
How do baseline characteristics differ by the selected grouping column?
```

This step should produce a basic **Table 1-style cohort summary**, but without p-values for now.

---

## Expected Outcome

After Step 5, the Cohort Overview tab should show:

```text
1. Cohort summary cards
2. Survival-ready cohort summary, if survival mapping exists
3. Variable-type summary
4. Numeric variable summaries
5. Categorical variable summaries
6. Optional group-wise summaries if a grouping column exists
7. Baseline characteristics table
8. Download button for baseline table as CSV
```

Example UI output:

```text
Cohort Overview
```

# 5. Core Design Principle

The Cohort Overview tab should summarize the **original uploaded dataset**, not only the survival-ready dataframe.

Reason:

```text
survival_ready_df only contains _time, _event, and optional _id/_group.
uploaded_df contains the actual clinical/demographic variables such as age, sex, treatment, stage, ECOG score, lab values, etc.
```

However, if survival mapping exists, use `survival_ready_df` to compute survival-specific counts:

```text
usable rows
events
censored
event rate
median follow-up
```

# 7. Dataset-Level Summary

Implement:

```python
def compute_cohort_overview_metrics(
    df: pd.DataFrame,
    survival_ready_df: pd.DataFrame | None = None,
    time_unit: str = "unknown",
) -> dict:
    ...
```

Return:

```python
{
    "n_rows": 228,
    "n_columns": 10,
    "complete_rows": 168,
    "complete_rows_percent": 73.68,
    "usable_survival_rows": 228,
    "events": 165,
    "censored": 63,
    "event_rate": 72.37,
    "median_followup": 305.0,
    "max_followup": 1022.0,
    "time_unit": "days",
}
```

Rules:

```text
n_rows = number of rows in uploaded_df
n_columns = number of columns in uploaded_df
complete_rows = rows in uploaded_df with no missing values
complete_rows_percent = complete_rows / n_rows * 100

If survival_ready_df exists:
    usable_survival_rows = number of rows in survival_ready_df
    events = count where _event == 1
    censored = count where _event == 0
    event_rate = events / usable_survival_rows * 100
    median_followup = median of _time
    max_followup = max of _time

If survival_ready_df does not exist:
    survival-related fields should be None
```

Round percentages to 2 decimals.

Do not mutate input dataframes.

# 8. Variable Classification

The Cohort Overview tab needs to decide how to summarize each column.

Implement:

```python
def classify_summary_variable(
    column_name: str,
    series: pd.Series,
    profile_row: dict | None = None,
    survival_config=None,
) -> str:
    ...
```

Return one of:

```text
continuous
categorical
datetime
text
id
excluded
```

---

## 8.1 Default Classification Rules

### Exclude survival mapping columns by default

If `survival_config` exists:

```text
time_col     -> excluded
event_col    -> excluded
id_col       -> id
group_col    -> categorical
```

Reason:

```text
time and event are already summarized separately in survival metrics.
id column should not appear as a baseline variable.
group column can appear because it is clinically meaningful.
```

---

### ID columns

Return `id` if:

```text
column name suggests ID
or profile_row["is_id_like"] is True
or unique_ratio >= 0.95 and non_missing_count > 10
```

ID columns should be excluded from baseline table by default.

---

### Continuous variables

Return `continuous` if:

```text
numeric_parse_rate >= 0.95
AND unique_count > 10
AND not id-like
AND not binary-like
```

Examples:

```text
age
meal.cal
wt.loss
lab values
follow-up duration if not already excluded
```

---

### Categorical variables

Return `categorical` if:

```text
is_binary_like is True
OR detected_type is boolean/categorical
OR 2 <= unique_count <= 20
```

Examples:

```text
sex
treatment
stage
ph.ecog
status labels if not already event_col
```

Important:

```text
Numeric-coded variables with low unique count should usually be categorical/ordinal, not continuous.
```

Examples:

```text
sex = 1/2
ph.ecog = 0/1/2/3
stage = 1/2/3/4
```

---

### Datetime variables

Return `datetime` if:

```text
date_parse_rate >= 0.8
```

Datetime variables can be summarized separately later. For Step 5, exclude them from baseline table by default unless user explicitly selects them.

---

### Text variables

Return `text` if:

```text
detected_type is text
or average string length is high
or unique_count is large and values are object/string
```

Exclude free-text variables from baseline table by default.

# 10. Numeric Variable Summary

Implement:

```python
def summarize_continuous_variable(
    df: pd.DataFrame,
    column: str,
) -> dict:
    ...
```

Return:

```python
{
    "variable": "age",
    "n": 228,
    "missing": 0,
    "mean": 62.45,
    "sd": 9.07,
    "median": 63.0,
    "q1": 56.0,
    "q3": 69.0,
    "min": 39.0,
    "max": 82.0,
    "summary": "62.45 ± 9.07; median 63.0 [56.0, 69.0]"
}
```

Rules:

```text
Parse column as numeric using pd.to_numeric(errors="coerce").
n = non-missing numeric values.
missing = original rows - n.
mean and sd rounded to 2 decimals.
median, q1, q3, min, max rounded to 2 decimals.
summary = "mean ± sd; median [q1, q3]"
```

If no numeric values exist:

```text
Return n = 0 and summary = "Not available"
```

# 11. Categorical Variable Summary

Implement:

```python
def summarize_categorical_variable(
    df: pd.DataFrame,
    column: str,
    max_levels: int = 10,
    include_missing: bool = True,
) -> pd.DataFrame:
    ...
```

Return a dataframe with one row per level:

```text
variable
level
count
percent
summary
```

Example:

| variable | level | count | percent | summary      |
| -------- | ----- | ----: | ------: | ------------ |
| sex      | 1     |   138 |   60.53 | 138 (60.53%) |
| sex      | 2     |    90 |   39.47 | 90 (39.47%)  |

Rules:

```text
Use non-missing values for normal level percentages.
If include_missing=True, add a missing row when missing_count > 0.
Sort levels by count descending.
If number of unique levels > max_levels:
    keep top max_levels
    collapse the rest into "Other"
```

Percent denominator:

```text
For non-missing levels:
    percent = count / non_missing_count * 100

For missing level:
    percent = missing_count / total rows * 100
```

Round percentages to 2 decimals.
