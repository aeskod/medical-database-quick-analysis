# Development Step 3: Basic Kaplan–Meier Survival Analysis

## Goal

Implement the first actual survival-analysis functionality using the confirmed mapping from Step 2.

This step should answer:

```text
Given a confirmed survival mapping, can the app:
1. Build a Kaplan–Meier survival curve?
2. Show basic survival summary statistics?
3. Optionally split the curve by one grouping variable?
4. Display the results in the Survival Analysis tab?
```

The app should now move from “mapping confirmed” to “basic survival analysis visible.”

---

## Expected Outcome

After the user uploads a dataset and confirms survival mapping, the **Survival Analysis** tab should show:

```text
1. Survival-analysis readiness message
2. Summary cards:
   - usable rows
   - events
   - censored
   - event rate
   - median survival
   - max follow-up time
3. Kaplan–Meier curve
4. Optional grouped Kaplan–Meier curve if group_col exists
5. Survival probability at selected time points
6. Clear warnings for small groups or missing group values
```


## 6.2 Function: `get_survival_summary`

Signature:

```python
def get_survival_summary(df: pd.DataFrame, time_unit: str = "unknown") -> dict:
    ...
```

Input:

```text
survival_ready_df containing _time and _event
```

Return:

```python
{
    "n": 228,
    "events": 165,
    "censored": 63,
    "event_rate": 72.37,
    "median_followup": 310.0,
    "max_followup": 1022.0,
    "time_unit": "days"
}
```

Rules:

```text
n = number of rows after dropping rows with missing _time or _event
events = count where _event == 1
censored = count where _event == 0
event_rate = events / n * 100
median_followup = median of _time
max_followup = max of _time
```

Round percentages to 2 decimals.

## 6.4 Function: `fit_km_by_group`

Signature:

```python
def fit_km_by_group(
    df: pd.DataFrame,
    group_col: str = "_group",
    min_group_size: int = 5,
    max_groups: int = 8
) -> tuple[list[dict], list[str]]:
    ...
```

Return:

```python
(group_results, warnings)
```

Where `group_results` is a list of dictionaries in the same format as `fit_km_overall`.

### Behavior

If `_group` is missing:

```text
Return empty group_results and warning.
```

If `_group` has missing values:

```text
Exclude rows with missing _group from grouped KM fitting.
Add warning: "Rows with missing group values were excluded from grouped analysis."
```

If number of groups exceeds `max_groups`:

```text
Do not fit grouped KM.
Return warning:
"Selected grouping column has too many groups for a readable KM plot."
```

If a group has fewer than `min_group_size` rows:

```text
Still fit the curve, but add warning:
"Group X has fewer than 5 rows. Interpret cautiously."
```

Group labels should be converted to strings for plotting.

---

## 6.5 Function: `suggest_timepoints`

Signature:

```python
def suggest_timepoints(max_time: float, time_unit: str = "unknown") -> list[float]:
    ...
```

Purpose:

Generate sensible default time points for showing survival probabilities.

### Rules

If `time_unit == "days"`:

```text
Use [30, 90, 180, 365, 730, 1095, 1825]
Keep only values <= max_time.
```

If `time_unit == "months"`:

```text
Use [1, 3, 6, 12, 24, 36, 60]
Keep only values <= max_time.
```

If `time_unit == "years"`:

```text
Use [1, 3, 5, 10]
Keep only values <= max_time.
```

If no suggested value is <= max_time, or time unit is `unknown`:

```text
Use approximate quartiles of max_time:
[0.25 * max_time, 0.5 * max_time, 0.75 * max_time]
```

Round generated values to 2 decimals.

# 9. Data Handling Rules

## 9.1 Do not mutate original data

All survival operations should work on copies.

## 9.2 Drop invalid rows only inside survival functions

Rows with missing `_time` or `_event` should be dropped from survival fitting.

Do not remove them from the original uploaded DataFrame.

## 9.3 Event format

`_event` should be treated as:

```text
1 = event occurred
0 = censored
```

Before fitting, cast to integer or boolean.
