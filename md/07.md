# 07.md — Development Step 7: Survival Analysis Improvements

## Goal

Improve the existing **Survival Analysis** tab.

The dashboard already supports:

```text
Step 1: Upload + preview + column profiling
Step 2: Survival role candidate detection + confirmed survival mapping
Step 3: Basic Kaplan–Meier survival analysis
Step 4: Data Quality tab
Step 5: Cohort Overview tab with baseline table
Step 6: Charts tab
```

Step 7 should enhance the existing Kaplan–Meier workflow without changing the overall architecture.

The Survival Analysis tab should now answer:

```text
Are survival curves different between groups?
How many patients are at risk over time?
What is the median survival for each group?
How many events and censored observations are in each group?
What is the survival probability at selected time points for each group?
Are the group sizes too small?
Are there too few events?
Do curves cross, making log-rank interpretation less reliable?
```

This step should **not** add Cox regression yet.

---

After Step 7, the Survival Analysis tab should show:

```text
1. Existing overall/grouped Kaplan–Meier plot
2. Group-wise survival summary table

5. Number-at-risk table

8. Optional group value labels for plot/table display

def compute_group_survival_summary(

    original_group_col: str | None = None,
) -> pd.DataFrame:
    ...
```

Return:

```text
group
raw_group
n
events
censored
event_rate
median_followup
max_followup
median_survival
time_unit
```

Example:

| group  | raw_group |   n | events | censored | event_rate | median_followup | median_survival |
| ------ | --------- | --: | -----: | -------: | ---------: | --------------: | --------------: |
| Male   | 1         | 138 |    112 |       26 |      81.16 |             270 |             270 |
| Female | 2         |  90 |     53 |       37 |      58.89 |             426 |             426 |

Rules:

```text
Use only rows with non-missing _time, _event, and _group.
Group by _group.
events = count where _event == 1.
censored = count where _event == 0.
event_rate = events / n * 100.
median_followup = median of _time.
max_followup = max of _time.
median_survival = median survival from KaplanMeierFitter for that group.
If median survival is not reached, store None or np.inf internally and display "Not reached" in UI.
Round percentages to 2 decimals.
Do not mutate survival_ready_df.
```

If `_group` does not exist:

```text
Return empty DataFrame.
```

## 9.1 Overall Log-Rank Test

```python

    survival_ready_df: pd.DataFrame,
    group_col: str = "_group",

```

Return:

```python
{
    "available": True,
    "method": "multivariate_logrank_test",
    "test_statistic": 10.33,
    "p_value": 0.0013,
    "degrees_of_freedom": 1,
    "n_groups": 2,
    "warnings": []
}
```

If test cannot run:

```python
{
    "available": False,
    "reason": "At least two groups with usable rows are required.",
    "warnings": [...]
}
```

Rules:

```text
Use only rows with non-missing _time, _event, and _group.
Require at least 2 groups.
Require each group to have at least 1 row.
Prefer multivariate_logrank_test so it works for 2 or more groups.
Do not run if all events are 0.
Do not run if no censored/event variation exists.
Round p-value only for display, not internally.
```

Use:

```python
from lifelines.statistics import multivariate_logrank_test
```

Expected call:

```python
result = multivariate_logrank_test(
    event_durations=df["_time"],
    groups=df[group_col],
    event_observed=df["_event"]
)
```

Return:

```text
test_statistic = result.test_statistic
p_value = result.p_value
degrees_of_freedom = number of groups - 1
```

## 12.1 Curve Crossing Heuristic

Implement a simple heuristic.

Input can be either:

```text
combined curve dataframe from combine_curve_results
```

or recompute inside the function.

Preferred implementation:

```python
def detect_curve_crossing(curve_df: pd.DataFrame) -> bool:
    ...
```

Rules:

```text
Only apply if there are at least 2 groups.
Pivot survival probabilities by time and group.
Forward-fill survival probabilities across times.
For each pair of groups, check whether the sign of survival difference changes over time.
If sign changes from positive to negative or negative to positive, return True.
Ignore timepoints where either group has missing survival.
```

This is a heuristic, not a formal statistical test.

If crossing detected, show:

```text
Survival curves may cross. The log-rank test can be less reliable when hazards are not proportional.
```
