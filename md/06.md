# 6. Core Design Principle

The Charts tab should guide the user toward reasonable chart choices.

Do not make the user choose from a huge list of chart types without help.

Use this pattern:

```text
User selects variable(s)
→ app detects variable types
→ app suggests chart type
→ user can override chart type
→ chart is displayed
```

For example:

```text
one numeric variable
→ histogram

one categorical variable
→ bar chart

numeric + categorical
→ box plot

numeric + numeric
→ scatter plot

categorical + categorical
→ grouped/stacked bar chart
```

# 8. Chart Variable Types

Use the existing `profile_df` and/or Step 5 variable classification to classify chart variables.

Implement:

```python
def get_chart_variable_type(
    column_name: str,
    df: pd.DataFrame,
    profile_df: pd.DataFrame | None = None,
) -> str:
    ...
```

Return one of:

```text
numeric
categorical
datetime
text
id
unknown
```

Rules:

```text
numeric:
    numeric_parse_rate >= 0.95
    AND unique_count > 10
    AND not id-like

categorical:
    is_binary_like is True
    OR 2 <= unique_count <= 30
    OR detected_type is boolean/categorical

datetime:
    date_parse_rate >= 0.8

id:
    is_id_like is True
    OR column name strongly suggests ID

text:
    detected_type is text
    OR object column with high unique ratio and long values

unknown:
    fallback
```

Important:

```text
Numeric-coded low-cardinality columns should be categorical.
Examples:
sex = 1/2
stage = 1/2/3/4
ph.ecog = 0/1/2/3
```

# 9. Recommended Chart Types

Implement:

```python
def recommend_chart_type(
    x_col: str | None,
    y_col: str | None,
    df: pd.DataFrame,
    profile_df: pd.DataFrame | None = None,
) -> str:
    ...
```

Return one of:

```text
histogram
bar
box
scatter
stacked_bar
correlation_heatmap
missingness_bar
none
```

Rules:

```text
If x_col is None and y_col is None:
    return "none"

If x_col == "__missingness__":
    return "missingness_bar"

If x_col == "__correlation__":
    return "correlation_heatmap"

If x_col is numeric and y_col is None:
    return "histogram"

If x_col is categorical and y_col is None:
    return "bar"

If x_col is categorical and y_col is numeric:
    return "box"

If x_col is numeric and y_col is categorical:
    return "box"

If x_col is numeric and y_col is numeric:
    return "scatter"

If x_col is categorical and y_col is categorical:
    return "stacked_bar"

If either selected variable is text or id:
    return "none"
```
